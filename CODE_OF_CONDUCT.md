# Code of Conduct

## Our pledge

We want participation in Node Studio to be a harassment-free experience for everyone, regardless of age,
body size, disability, ethnicity, sex characteristics, gender identity and expression, experience,
education, socio-economic status, nationality, personal appearance, race, religion, or sexual identity
and orientation.

## Expected behaviour

- Be respectful and specific when discussing code, measurements and design.
- Assume good intent, but accept correction when the evidence disagrees.
- Keep critique about the work, not the person.
- Respect privacy: do not publish another person's data, credentials or private messages.
- Follow the project's zero-mock standard: label estimates, planned work and unimplemented features
  honestly.

## Unacceptable behaviour

Harassment, discriminatory language, personal attacks, doxxing, sustained disruption, and publishing
private information without permission are not acceptable.

## Enforcement

Maintainers may remove comments, close issues, reject pull requests or restrict participation when this
code is violated. Report concerns privately through the repository's **Security** tab or the maintainer
profile [@GaiDevOfficial](https://github.com/GaiDevOfficial).
