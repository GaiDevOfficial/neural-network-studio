# Node Studio 1.0.2

A verification, host-consistency and online-safety patch. The canvas, lessons and data paths are unchanged; the online correction trust region is tightened so repeated human corrections cannot rewrite the model's general decision boundary.

## Fixed

- **The MIME override is now actually in the shipped host.** The 1.0.1 note described pinning
  `text/javascript`, but the edit was lost before the commit. The desktop host inherited the Windows
  registry value and CI still received `application/javascript`. `StudioHTTPHandler.extensions_map`
  now explicitly maps `.js`, `.mjs`, `.css`, `.json`, `.map`, `.svg` and `.wasm`, and the host test pins
  the class map as well as the response header.
- **Playground accuracy smoke no longer races the evaluation.** `TRAINING_COMPLETE` and
  `TEST_SET_EVALUATED` are separate worker messages. The smoke now waits up to 15 seconds for the real
  held-out report after completion instead of reading the accuracy element in the gap.
- **Online corrections keep an aggregate trust region.** Coordinate clipping alone allowed six
  default-budget corrections on shifted MNIST mistakes to move thousands of small weights and drop
  held-out accuracy from 100% to 56.5%. The engine now also caps the L2 norm of the complete parameter
  delta. The corrected sample's loss still falls, while the six-correction guard stays at 100% across
  repeated runs.

## Changed

- `tools/push_with_backup.ps1` runs `python tools/smoke_node_studio.py` by default, so the full
  real-WebView2 interaction suite is part of every release. Use `-SkipUiSmoke` only for a deliberate
  fast path.

## Verification

- `npm test`: all JavaScript suites and the example certificate pass.
- `npm run test:python`: 27/27, including the pinned `.js` map assertion.
- `python tools/smoke_node_studio.py`: 108/108 in real WebView2, including the Playground held-out check.
- Packaged launcher: ready state, 27 palette blocks, zero failed resources.
- Microsoft Defender: portable folder and ZIP report no threats.

## Upgrade

Replace the previous portable folder with this ZIP. No installer or runtime is required.

The app is unsigned, so SmartScreen may show a first-run reputation warning. Trusted code signing is the
only universal fix for that warning.
