# Node Studio 1.0.0

The first public release of Node Studio: a Scratch-style visual neural-network builder that runs real
models on real data.

## Highlights

- **Three tiers, one engine** - Absolute Beginner Playground, Beginner Assist and Advanced Manual share
  the same graph compiler, Web Worker and datasets.
- **Real Playground** - the shipped MNIST 0-vs-1 brain trains on the real corpus; draw a digit, ask, and
  correct it with one measured online-backpropagation step.
- **Visual graph builder** - draggable blocks, bezier wires, live validation, Smart Assist repairs,
  right-click **Break connection**, drag-to-delete and cursor-anchored quick-add.
- **Real training dashboard** - epoch, train/held-out loss, accuracy, best epoch, convergence stall,
  loss sparkline and a per-class confusion matrix.
- **Data you can actually load** - built-in benchmarks, real MNIST, CSV upload, SQLite, local CSV paths
  and REST/JSON through the local Data API.
- **Exports that run** - graph JSON, model JSON, Python/NumPy, JavaScript ES module, `.npz` and ONNX
  (opset 13, IR 8), verified against the engine.
- **Ten lessons and three missions** - step-by-step guides with real action gates, moving highlights and
  cards that never cover the target.
- **Portable Windows build** - one folder, no installer, no Python or Node runtime required.

## Distribution

Download `NeuralNetworkStudio-Windows-x64.zip`, verify the attached SHA-256, extract the folder and run
`NeuralNetworkStudio\NeuralNetworkStudio.exe`.

The ZIP is the portable one-folder build. The developer-only one-file executable is not distributed
because Windows Defender flags its self-extracting bootloader as a heuristic false positive.

## Verification

- All JavaScript and Python suites pass.
- The real-WebView2 UI smoke passes 108/108 checks.
- The packaged launcher reaches `Ready - build a graph or load a preset.` with 27 palette blocks and zero
  failed module requests.
- A Microsoft Defender custom scan of the portable folder and ZIP reports no threats.

The app is unsigned, so Windows SmartScreen may show a first-run reputation warning on another machine.
Trusted code signing is the only universal fix for that warning.
