# Node Studio 1.0.1

A small reliability release for the 1.0 line. The canvas, engine, lessons and releases are unchanged.

## Fixed

- **Consistent JavaScript MIME types.** The desktop host and `server.py` now pin the web-standard
  `text/javascript` for `.js`/`.mjs`, plus explicit values for CSS, JSON, source maps, SVG and WASM.
  Windows machines can otherwise return `application/javascript`, which is valid in browsers but made
  the host MIME check depend on the runner's registry.
- **Release versioning.** `tools/push_with_backup.ps1` now updates `package.json` to the tag version
  before committing, so the package metadata cannot drift behind the release.

## Verification

- `npm test` passes all JavaScript suites and the example certificate.
- `npm run test:python` passes 27/27 checks, including the MIME regression on the desktop host.
- The real-WebView2 smoke passes 108/108 checks.
- The packaged portable launcher reaches the Node Studio ready state with 27 palette blocks and zero
  failed resources.
- Microsoft Defender scans the portable folder and ZIP with no threats.

## Upgrade

Download `NeuralNetworkStudio-Windows-x64.zip`, verify the attached SHA-256, and replace the previous
portable folder. No installer or runtime is required.

The app is unsigned, so SmartScreen may show a first-run reputation warning. Trusted code signing is the
only universal fix for that warning.
